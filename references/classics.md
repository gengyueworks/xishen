# 命理分析关键概念（供分析时调用，基于古籍框架整理）

## 十神（以日干为"我"）
- 比肩 / 劫财：同我者（比肩同性，劫财异性）
- 食神 / 伤官：我生者（食神同性，伤官异性）
- 正财 / 偏财：我克者（正财异性，偏财同性）
- 正官 / 七杀（偏官）：克我者（正官异性，七杀同性）
- 正印 / 偏印（枭神）：生我者（正印异性，偏印同性）
格局看十神组合与强弱配比。

## 日主强弱判断（《滴天髓》《子平真诠》法）
- **得令**：生于当令之月（如甲乙木生于春）
- **得地**：地支有本气根（如木见寅卯）
- **得生**：天干/地支有印星生扶
- 三者得二以上多偏强，反之偏弱；还要看克泄耗的力量。

## 用神 / 喜忌
- 偏弱：喜生扶（印、比劫）
- 偏强：喜克泄耗（官杀、食伤、财）
- **调候**：寒暖燥湿——冬生喜火、夏生喜水，需水火调候（《滴天髓》"天道有寒暖，地道有燥湿"）

## 大运（《三命通会》法）
- 顺逆：阳年男 / 阴年女顺排，阴年男 / 阳年女逆排
- 起运：三天为一岁，从出生日数到最近节气（顺数未来、逆数过去），得几日折几岁几月起运

## 流年
- 流年干支与四柱、大运的生克、刑冲合害（三合、六合、三刑、六冲等）
- 重点看：流年是否与日主/用神有情，是否冲克忌神

## 取象与断语（《玉照定真经》《渊海子平》）
- 干为天、为外、为显；支为地、为内、为藏
- 十神叠加宫位（年柱祖上、月柱父母兄弟、日柱自身配偶、时柱子女）取象推断
