# 太乙 · 奇门遁甲（玄学暖读 · 大势 / 地机 维度参考）

> 本文件是 xishen 技能的**可选维度参考资料**，不是算命算法书。目的是：当用户拿"太乙 / 奇门"说事，或问"大势 / 时代 / 选择 / 时机"时，技能能**有根有据地接话、不露怯、不编造**。真正的个人命理仍由八字（`classics.md`）计算；太乙 / 奇门在这里只提供**文化谱系与框架视角**。

## 三式同源：天、地、人

太乙、奇门遁甲、大六壬，并称"三式"，是中国古代最高层级的推演之术，同出易理，共宗阴阳五行、九宫干支，都以"式盘"为工具模拟时空。三者分工：

- **太乙（天元）— 主天运**：问王朝兴衰、天下治乱、灾异丰歉、历史周期。尺度宏大，**不占私人琐事**。
- **奇门（地元）— 主地机 / 时空格局**：问方位、时机、布局、行军谋略、环境吉凶。重空间与动态选择。
- **六壬（人元）— 主人事**：问日常百事、人际、官非、婚姻、求财。类象最细，应用最广。

映射到本技能的可选维度：

- 用户问"未来 / AI / 时代 / 国运级趋势" → 落在**太乙（天运）**谱系，用"问大势"维度接。
- 用户问"我该不该动 / 何时出手 / 选哪条路 / 怎么布局" → 落在**奇门（地机）**谱系，用"问选择 / 时机"维度接。
- （六壬偏日常人事，本技能以八字覆盖个人，不单列。）

## 太乙神数（天运 · 问大势的谱系）

- **定位**：三式之首，古代"帝王之术"，司天监专用，推国运、灾变、周期。普通人不占私事。
- **结构骨架**：洛书九宫为基（太乙**不入中宫**，只行八宫）；配**十六神**、**八将**（太乙、文昌 / 天目、始击 / 客目、计神、主大将、主参将、客大将、客参将）、三基、五福、十精。
- **周期观**：五元六纪——一元 72 年，五元 360 年为大周期；太乙每宫三年，24 年转一周。重"积年""历史节律"，近似"历史天文学"。
- **给本技能的启发**：当用户焦虑"时代巨变 / AI 替代"，借太乙"天运周期"的视角——把眼前震荡放进更长的人文周期里看，强调"周期里有起伏，人可以在自己的大运流年里找窗口"，而非断言具体年份。

## 奇门遁甲（地机 · 问选择 / 时机的谱系）

- **定位**：三式之一，古称"遁甲主兵"，主方位、时机、格局、谋略；宋后民间放开，衍生择吉、风水、布局。
- **结构骨架**：九宫 + 八卦 + **九星**（天蓬…天英）、**八门**（开休生伤杜景死惊）、**三奇**（乙丙丁）、**六仪**（戊己庚辛壬癸）、**八神**（值符、螣蛇、太阴、六合、白虎、玄武、九地、九天）。天地人三盘叠加。
- **核心思维**：格局思维——吉凶取决于"门、星、奇"的组合与方位，强调动态平衡、在时空里找最优解。
- **给本技能的启发**：当用户问"要不要换工作 / 何时出手 / 选哪条路"，借奇门"时空格局 / 择机"的视角——把决策翻译成"你的八字大运流年 + 当前格局里哪个方向（事业 / 关系 / 学习）正旺"，给一步能迈的具体动作，而非排一盘奇门。

## 边界（铁律，不可破）

- **不伪造盘式**：本技能**不会**真的排出太乙式盘或奇门局（那需要完整历法 / 积年算法与式盘工具，不在能力内，也不该假装）。用户若甩出"太乙说 XX 年 / 奇门说 XX 方"，只当作一种**未来观 / 文化参照**，用八字 + 情绪价值引擎回应。
- **不预言具体年份 / 事件 / 方位吉凶**：禁止"27 年必失业""某方必吉"之类断言。
- **情绪价值优先**：无论借太乙（天运）还是奇门（地机），落点都是"把你八字里的亮点翻译成机器 / 时代难替代的部分"，把焦虑翻成希望。
